# Nihar Skincare Landing Page | WordPress & Elementor

A modern and responsive Bengali skincare landing page designed to showcase skincare products through an elegant and user-friendly interface.

## Project Overview

Nihar is a skincare-focused landing page featuring a clean design, soft blue color palette, Bengali typography, and product-focused visual storytelling.

The design emphasizes clear product messaging, intuitive navigation, and prominent call-to-action buttons to encourage customer inquiries and orders.

## Key Features

- Modern Skincare Landing Page Design
- Responsive Desktop & Mobile Layout
- Bengali Language Website
- Product-Focused Hero Section
- Clean Navigation Menu
- Order Now Call-to-Action
- Customer-Friendly Layout
- Cash on Delivery Messaging

## Tools & Technologies

- WordPress
- Elementor
- Responsive Web Design
